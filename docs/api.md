# API-Design

Basis: `/api/v1`

- Auth: `/auth/login`, `/auth/me`, `/auth/users`
- Checks: `/checks/run`
- Monitors: `/monitors`, `/monitors/{id}`, `/monitors/{id}/runs`
- Listen: `/lists`
- Alert-Channels: `/channels`
- Dashboard: `/dashboard`
- Betrieb: `/system/health`, `/system/live`, `/system/ready`

Swagger/OpenAPI:
- `/docs`
- `/openapi.json`
